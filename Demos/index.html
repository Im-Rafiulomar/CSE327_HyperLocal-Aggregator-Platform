03 / Problem Analysis

Problem Statement & Market Gap

❌ Local Vendor Isolation

  • Neighborhood grocery and retail vendors lack digital exposure and real-time inventory visibility.
  • Centralized e-commerce giants charge steep commissions and slow delivery timelines.
  • Inability to present dynamic stock updates to nearby local buyers.

❌ Search & Logistics Friction

  • Customers struggle to find specific local items (e.g. fresh regional produce) within walking distance.
  • Traditional search lacks regional voice & visual camera object recognition.
  • Static pricing eliminates conventional micro-bargaining and localized fleet dispatch.
04 / Requirements

Requirement Analysis

Functional Requirements

  • Multimodal AI Search: Voice dialect processing and camera visual vector matching.
  • Live GPS Telemetry: Real-time delivery fleet tracking with dynamic ETA countdowns.
  • Vendor Catalog & AI Bargain Engine: Automated negotiation and multi-store inventory synchronization.

Non-Functional Requirements

  • Low Latency: Sub-second catalog search and dynamic GPS updates every 50ms.
  • Scalability: Modular architecture supporting over 100+ distinct local vendor items per hub.
  • Usability: Fully responsive, high-contrast UI tailored for desktop and mobile devices.
05 / Feasibility

Feasibility Analysis

🛠️ Technical Feasibility

Built using standard Web APIs, SVG canvas manipulation, and Vanilla JavaScript ESM, eliminating heavy framework overhead while guaranteeing cross-browser support.

⚙️ Operational Feasibility

Intuitive dual-interface for local store vendors and buyers requires zero technical training, ensuring smooth neighborhood adoption.

💰 Economic Feasibility

Utilizes open-source standards and lightweight local API endpoints, drastically reducing infrastructure costs compared to monolithic cloud setups.

06 / System Architecture

UML Use Case Diagram

👥 Primary Actors

  • Customer: Initiates multimodal search, negotiates deals, places orders, tracks riders.
  • Store Vendor: Syncs 100 unique stock items, monitors orders, reviews ratings.
  • Delivery Fleet: Transmits 50ms GPS telemetry, executes localized drop-offs.

🤖 System Actor & Relations

  • AI Engine: Computes feature-vector matching, runs dialect speech NLP, auto-negotiates prices.
  • «extend»: AI Price Negotiation extends product search during bulk purchases.
  • «include»: Order placement explicitly incorporates live GPS fleet tracking.

⚡ Decoupled Engine Architecture

Guarantees sub-second response times for multi-store catalog sync and dynamic GPS telemetry streaming.
